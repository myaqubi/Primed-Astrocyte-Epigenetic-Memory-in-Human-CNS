# In vivo multiome analysis

This folder contains the analysis workflow used for preprocessing, quality control, integration, donor demultiplexing, and downstream preparation of the in vivo single-nucleus multiome (snRNA-seq + snATAC-seq) dataset.

## Script order

### 1. `01_sample_preprocessing_QC.R`

Performs initial processing and quality control separately for each multiplexed sample.

- Reads filtered RNA/ATAC matrices and raw RNA matrices from Cell Ranger output.
- Creates Seurat/Signac multiome objects.
- Performs preliminary RNA normalization and clustering required for SoupX.
- Applies SoupX for ambient RNA correction.
- Calculates nuclear fraction.
- Applies DropletQC to identify and remove empty droplets.

### 2. `02_merge_consensus_peaks.R`

Merges the individually processed samples and generates a common ATAC feature space.

- Merges the preprocessed multiome objects.
- Constructs a unified ATAC peak set across all samples.
- Re-quantifies ATAC fragments using the consensus peak set.
- Retains peaks located on standard hg38 chromosomes.
- Calculates RNA- and ATAC-based quality-control metrics for the merged object.

### 3. `03_post_merge_QC.R`

Performs quality-control filtering on the merged multiome dataset.

- Identifies QC outliers separately within each multiplexed sample using a 5-median absolute deviation (MAD) approach.
- Uses RNA and ATAC QC metrics, including RNA feature/count distributions, mitochondrial RNA percentage, ATAC feature/count distributions, TSS enrichment, and nucleosome signal.
- Generates the QC-filtered merged multiome object used for downstream integration.

### 4. `04_RNA_integration.R`

Performs RNA preprocessing and sample integration.

- Normalizes RNA expression.
- Identifies highly variable genes.
- Performs cell-cycle scoring and data scaling.
- Runs PCA and RNA-based UMAP.
- Integrates samples using cluster similarity spectrum (CSS).
- Generates the integrated RNA representation used in downstream multimodal analysis.

### 5. `05_ATAC_integration.R`

Performs ATAC dimensionality reduction and sample integration.

- Identifies informative ATAC features.
- Performs TF-IDF normalization.
- Runs singular value decomposition/latent semantic indexing (SVD/LSI).
- Generates the ATAC UMAP.
- Integrates ATAC profiles across samples using CSS.

### 6. `06_WNN_integration.R`

Combines the integrated RNA and ATAC representations.

- Integrates the RNA and ATAC CSS reductions using weighted nearest neighbors (WNN).
- Generates the joint multimodal UMAP.
- Performs clustering using the weighted shared nearest-neighbor (WSNN) graph.

### 7. `07_donor_demultiplexing.R`

Assigns nuclei from each multiplexed sample to their corresponding biological donors.

- Reads the donor-assignment results generated for each multiplexed sample.
- Separates `donor0` and `donor1` assignments within each sample.
- Examines expression of sex-associated genes (`XIST`, `DDX3Y`, `SRY`, `ZFY`, and `USP9Y`) to support assignment of the demultiplexed groups to the corresponding biological donors.
- Explicitly records the donor identity, disease group, sample, and sex for each confidently assigned donor population.
- Retains nuclei classified as unassigned without assigning donor-specific metadata.
- Adds the donor annotations back to the complete multiome object.
- Generates simplified donor labels used in downstream single-cell analyses:



## Running the workflow

Scripts should be run in numerical order. Intermediate RDS files are saved between major analysis stages, allowing individual scripts to be run in separate R sessions when required.

Before running the workflow, update the base directory in the relevant scripts:

```r
base_dir <- "PATH/TO/MULTIOME_DATA"
```

The expected per-sample Cell Ranger output files used during initial preprocessing are:

- `filtered_feature_bc_matrix.h5`
- `raw_feature_bc_matrix.h5`
- `atac_fragments.tsv.gz`
- `possorted_genome_bam.bam`

The donor-demultiplexing script additionally requires the corresponding matched donor-assignment files for each multiplexed sample (for example, `matched_barcodes_Sample1.csv`). This step was performed by running **cellSNP-lite** on the BAM files generated by the Cell Ranger pipeline, followed by **Vireo** using the cellSNP-lite output for donor demultiplexing.
